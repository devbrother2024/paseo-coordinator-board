# Intent: 계정 카드에 사용량 초기화권의 남은 장수와 만료를 보인다

생성: 2026-11-25 유지관리자 요청, 구현 뒤 작성
승인: 2026-11-25 유지관리자(세션)
상태: 구현됨 (PR #59)

## 문제

일부 구독은 사용량 초기화권(주간 한도를 처음으로 되돌리는 무료 초기화, 특정 모델 몫만 되돌리는 초기화)을 준다. 몇 장 남았고 언제 만료되는지는 Paseo 사용량 보고에 없어서, 설정의 계정 카드만 보고는 한도가 바닥났을 때 되돌릴 수단이 있는지 알 수 없다.

## 바뀐 뒤의 모습

호스트 관리자가 두는 `account-usage.json`에 초기화권을 적으면, 계정 카드에 초기화권마다 남은 장수, 아직 지나지 않은 가장 가까운 만료와 그때까지 남은 시간이 보인다. Paseo가 사용량을 직접 재는 실행기도 같은 파일로 초기화권만 덧붙일 수 있다.

## 영향받는 사람과 화면

- 호스트 관리자: `account-usage.json` 형식에 선택 칸 하나가 는다.
- 보드 사용자: 설정 → 계정과 사용량의 계정 카드.

## 제약

- 보드는 일반 형식만 정하고, 실제 값은 각 호스트의 운영 도구가 채운다. 특정 구독이나 실행기를 코드에 넣지 않는다.
- 표시 전용이다. 자동 배정과 사용량 기준 정렬은 지금처럼 Paseo의 사용량 보고만 쓴다.
- 파일 읽기는 지금처럼 심볼릭 링크를 따르지 않고 크기 상한을 둔다.

## 하지 않을 것

- 초기화권 사용(되돌리기 실행), 남은 장수 계산, 배정 판단에 반영.
- 파일의 창·잔액으로 Paseo의 측정값을 덮기.
- 실행기별 초기화권 종류를 보드가 알기.

## 버린 대안

- 초기화권을 표시 전용 카드(호스트 추가 보고)에만 보이기: Paseo가 사용량을 재는 실행기는 파일 값을 하나도 쓰지 않으므로, 가장 필요한 계정에 초기화권이 보이지 않는다.
- 같은 실행기의 파일 보고를 Paseo 보고 전체와 바꿔 끼우기: 낡거나 틀린 파일 값이 Paseo의 새 측정을 가린다.
- 보드에 특정 구독의 초기화권 규칙을 넣기: 공개 플러그인에 한 호스트의 운영 사정을 묶는다.

## 성공 기준

- 형식이 맞는 초기화권은 계정 카드에 보이고, 틀린 항목 하나 때문에 보고 전체가 사라지지 않는다.
- Paseo 측정 계정의 창·잔액과 조회 시각은 파일이 있어도 그대로다.
- 낡은 파일 값이 Paseo의 새 측정 시각 아래에서 신선하게 보이지 않는다.
- 파일이 없거나 `resetPasses`가 없으면 화면과 동작이 이전과 같다.

## spec에서 정할 것

필드와 상한, 항목별 검사, Paseo 측정 계정과 파일 보고를 짝짓는 규칙, 초기화권 조회 시각 표시, 옛 파일·옛 보드와의 호환.
