# Spec: 코디네이터 대기 표시와 원격 조회 범위

Intent: [intent.md](intent.md)
승인: 2026-11-25 유지관리자(세션)
상태: 승인

## 범위

세션 진행의 두 보기. 보드 스냅숏의 표시 항목과 다른 호스트에서 읽는 자료의 범위를 기록한다.

## 동작 계약

- R1. 이후 입력이 없는 마지막 어시스턴트 글을 판정한다. 인용·코드 속 예시를 건너뛰고 직접 결정 요청과 권한 요청을 우선한다. 사람의 답을 기다린다고 적혀 있으면 코디네이터 대기에서 제외한다. 대기 상대가 생략되면 인접 문장에서 코디네이터가 맡은 일을 확인한다.
- R2. 기존 상태와 판단을 보존하고, 스냅숏의 선택 항목에 대기 이유를 담는다. 진행 칸과 모아보기에서 이유를 표시한다. 이미 보드에 남아 있는 미처리 대화·원장 결정은 내 결정에서도 계속 표시한다. 30분부터 경과 시간을 강조하고 지정 세션을 열 수 있을 때 코디네이터 열기를 제공한다.
- R3. 연결 및 표시 중인 호스트의 프로젝트 소속을 먼저 확인한다. 실행 중인 세션은 기존 메타데이터로 표시한다. 권한 대기, 오류, 보관 상태를 제외한 유휴 세션만 최신 타임라인 발췌를 읽는다. 판정과 시각만 화면에 쓰고 새 메시지 전송은 추가하지 않는다.
- R4. 원격 발췌 실패는 해당 대기 표시만 생략한다. 활동 시각이 같으면 이전 분류를 재사용한다. 프로젝트 선택이나 호스트 표시 설정을 바꾸면 이전 조회의 결과를 버린다. 대기 중인 원격 세션은 병합을 보류시키는 실행 중 세션으로 세지 않는다.
