# Intent: 코디네이터 응답을 기다리는 세션을 진행 화면에 표시

생성: 2026-11-25 유지관리자 요청
승인: 2026-11-25 유지관리자(세션)
상태: 승인

## 문제

작업 세션이 화면 차례나 판단을 기다려 멈춰도 보드에서는 일반 대기 상태로 보인다. 보드에서 배정하지 않은 원격 세션은 진행 목록이 실행 상태만 조회하므로 멈추면 목록에서 사라진다.

## 바뀐 뒤의 모습

세션 진행의 두 보기에서 코디네이터 응답을 기다리는 이유와 오래된 대기를 확인한다. 직접 결정을 요청하면 기존 결정 카드의 우선순위를 따른다.

## 제약

프로젝트 소속과 표시 여부를 이미 확인한 호스트의 세션에 한해 발췌를 조회한다. 화면 상태에는 분류된 이유와 대기 시작 시각만 보관한다. 모든 질문 응답은 기존 흐름을 따른다.

## 버린 대안

보드 배정 세션의 기존 발췌만 쓰면 배정 기록이 없는 원격 세션이 계속 누락된다. 대상이 확인된 원격 세션에도 같은 발췌 판정을 적용한다.

## 성공 기준

로컬과 원격 작업 세션이 두 보기에 나타나고, 30분이 지나면 대기 상태와 기존 코디네이터 열기 동작이 강조된다.
