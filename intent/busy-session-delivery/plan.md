# 바쁜 세션의 카드 답장 구현 순서

승인: 2026-11-25 유지관리자(세션)
상태: 승인

[전송 계약](spec.md)

1. 현재 질문과 바뀐 질문, 대기 시간 경계와 권한 대기를 재현하는 실패 시험을 쓴다.
2. 원장과 세션 답장에 전송 조건을 적용한다. 세션 대화는 사람이 열었던 카드의 개정을 다시 확인한다.
3. 대기 예약의 보류·재개와 코디네이터 전송을 연결하고 중복 클릭과 전송 실패를 시험한다.
4. 설정, 한국어·영어 카드와 문서를 갱신한다. 예시 카드로 넓은 화면과 390px 화면을 확인한다.
5. 타입 검사, 전체 시험, ZIP 생성·무결성 검사와 공개 위생 검사를 거쳐 하나의 초안 PR로 제출한다.
