# Plan: 보드 배정 도구의 경로 선택 입력 추가

Spec: [spec.md](spec.md)
승인: 2026-11-25 유지관리자(세션)
상태: 구현됨 (PR #55)

## 단위

세션 경로로 한 브랜치와 한 PR에 설계 문서, 코드, 테스트를 담는다.

## 순서

1. 배정 도구의 원격 경로 선택과 재시도 테스트를 먼저 추가한다.
2. 선택적 입력을 읽고 대상 호스트의 카탈로그, 훅과 작업 모드를 검사한다. 출처를 기록하고 기존 생성 페이로드 재시도를 보존한다.
3. 도구 설명과 두 언어의 배정 안내를 갱신하고 `AGENTS.md`의 근거 줄 번호를 확인한다.

## 검증

- `bun test test/dispatch.test.ts test/multi-host-assignment.test.ts`로 R1~R3 확인.
- `npm ci`, `npm run typecheck`, `npm test`, `npm run package:zip`, 배포 ZIP 무결성 검사.
- 초안 PR의 공개 위생 검사와 운영체제별 CI.

## 위험과 확인할 것

도구의 입력과 설명이 바뀌면 도구 정의 지문이 바뀐다. 이전 정의를 기억하는 코디네이터에는 보드의 기존 교체 안내가 표시될 수 있다.
